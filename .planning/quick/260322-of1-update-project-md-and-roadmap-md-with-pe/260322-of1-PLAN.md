   - Gateway orchestrates sequential calls with compensating transactions

   - Cursor-based pagination for all list endpoints
   - Opaque URL-safe cursor value
   - Server -> client: `X-Next-Cursor` response header (omitted when no more pages)
   - Client -> server: `?cursor=` query parameter
   - Response body stays flat array
   - Page size: `?limit=N` (default 25, max 100)
   - Sort: `?sort=field-order` kebab-case (e.g., `?sort=created-at-desc`)

5. **Add "API Conventions" section** (per D-125, D-126):
   - Query string parameters: kebab-case (e.g., `?sort=created-at-desc`, `?limit=25`)
   - Request/response body fields: snake_case (e.g., `{ "user_id": "...", "recovery_codes": [...] }`)
