# Quick Task 260324-r69: Simplify NameInput Validation

**One-liner:** Replaced custom `check_name_length` fn + `validate_name()` wrapper with validator's built-in `#[validate(length(...))]` attribute, updating call sites to use `Validate::validate()` directly.

## What Changed

### `name_input.rs`

- Removed the 14-line `check_name_length` custom function
- Replaced `#[validate(custom(function = "check_name_length", ...))]` with `#[validate(length(min = 1, max = 20, message = "name must be 1-20 characters"))]`
- Removed the `validate_name()` wrapper method from `impl NameInput` (was just a thin wrapper calling `self.validate()` and formatting the error string)
- Updated tests to call `.validate()` directly and added `use validator::Validate` import in the test module

**Unicode correctness preserved:** validator 0.20 implements `ValidateLength` for `String` using `chars().count()` — the same method used by the removed custom function.

### `create_user.rs` and `update_user.rs`

- Added `use validator::Validate;` import to each file
- Changed:
  ```rust
  name_input.validate_name().map_err(UserError::InvalidName)?;
  ```
  to:
  ```rust
  name_input
      .validate()
      .map_err(|e| UserError::InvalidName(e.to_string()))?;
  ```
