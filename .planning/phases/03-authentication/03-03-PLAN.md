**`verify_jwt`** function (research Pattern 5):
1. Try standard decode with `Validation::new(Algorithm::ES256)`, set issuer=["madome-auth"], set audience=["madome-gateway"] (D-42)
2. If Ok -> return `Valid(claims)`
3. If Err with `ErrorKind::ExpiredSignature` -> retry decode with `validate_exp = false`
4. On success of lax decode: check `now <= claims.exp + 60` (D-34 grace period, research Pitfall 4). If within grace -> `ExpiredInGrace(claims)`. Otherwise -> `ExpiredPastGrace`
5. Any other error -> `Invalid`

**Extract credential from request** (research Pattern 8):
```rust
fn extract_token(headers: &HeaderMap, jar: &CookieJar) -> Option<AuthCredential> {
    // 1. Check Authorization: Bearer header
    if let Some(auth_header) = headers.get("authorization") {
        if let Ok(val) = auth_header.to_str() {
            if let Some(bearer) = val.strip_prefix("Bearer ") {
                // API key detection: prefix check first, then dot check (Pitfall 6)
                if bearer.starts_with("madome_sk_") {
                    return Some(AuthCredential::ApiKey(bearer.to_string()));
                }
            }
        }
    }
    // 2. Check cookie "token" (D-44)
    if let Some(cookie) = jar.get("token") {
        return Some(AuthCredential::Jwt(cookie.value().to_string()));
    }
    None
}

pub enum AuthCredential {
    Jwt(String),
    ApiKey(String),
}
```

**`AuthUser` extractor** implementing `FromRequestParts<AppState>`:

This is the core JWT extractor for protected routes. It:
1. Calls `extract_token` to get the credential
2. If no credential -> reject with `AppError::Unauthorized` (D-50)
3. If JWT:
   a. Call `verify_jwt` with the decoding key from AppState
   b. `Valid(claims)` -> extract user_id and role, return `AuthUser { user_id, role, name, session_id }`
   c. `ExpiredInGrace(claims)` -> call auth gRPC `RefreshToken(session_id)`, set new JWT cookie in response extensions, return `AuthUser`. Note: setting response cookies from an extractor requires using axum response extensions or a middleware layer approach. Use `parts.extensions.insert(NewJwtCookie(new_token))` and a response middleware layer that reads this extension and sets the cookie.
   d. `ExpiredPastGrace` -> call auth gRPC `ValidateSession(session_id)` using the session_id from expired claims (decode without exp validation). If session valid -> call `RefreshToken`, set cookie, return `AuthUser`. If invalid -> reject.
   e. `Invalid` -> immediate 401 (D-48)

```rust
#[derive(Debug, Clone)]
pub struct AuthUser {
    pub user_id: String,
    pub role: String,
    pub name: String,
    pub session_id: String,
}

// Signal to response middleware to set a new JWT cookie
#[derive(Debug, Clone)]
pub struct NewJwtCookie(pub String);
```

**`AdminUser` extractor**: Wraps `AuthUser`, rejects if `role != "admin"` with `AppError::Forbidden` (D-46).

```rust
pub struct AdminUser(pub AuthUser);

#[axum::async_trait]
impl<S: Send + Sync> FromRequestParts<S> for AdminUser
where
    AppState: FromRef<S>,
{
    type Rejection = AppError;

    async fn from_request_parts(parts: &mut Parts, state: &S) -> Result<Self, Self::Rejection> {
        let auth_user = AuthUser::from_request_parts(parts, state).await?;
        if auth_user.role != "admin" {
            return Err(AppError::Forbidden("forbidden".to_string()));
        }
        Ok(AdminUser(auth_user))
    }
}
```

**Cookie response middleware**: A tower `Layer`/`Service` that checks response extensions for `NewJwtCookie` and sets the `Set-Cookie` header with HttpOnly, Secure (configurable via `COOKIE_SECURE` env), SameSite=Strict, Path=/ (D-44). Use `axum_extra::extract::cookie::Cookie` to build the cookie.

Alternatively, implement this as an axum middleware function:
```rust
pub async fn jwt_cookie_middleware(
    State(state): State<AppState>,
    request: axum::http::Request<axum::body::Body>,
    next: axum::middleware::Next,
) -> axum::response::Response {
    let mut response = next.run(request).await;
    if let Some(new_cookie) = response.extensions().get::<NewJwtCookie>() {
        // Build Set-Cookie header
        let mut cookie = Cookie::new("token", new_cookie.0.clone());
        cookie.set_http_only(true);
        cookie.set_secure(state.cookie_secure);
        cookie.set_same_site(axum_extra::extract::cookie::SameSite::Strict);
        cookie.set_path("/");
        response.headers_mut().insert(
            axum::http::header::SET_COOKIE,
            cookie.to_string().parse().unwrap(),
        );
    }
    response
}
```

```rust
pub mod auth;

pub fn create_router(state: AppState) -> Router {

fn v1_routes(state: AppState) -> Router<AppState> {
    Router::new()

        // Public auth routes (D-47)
        .nest("/auth", public_auth_routes())
        // Protected auth routes
        .nest("/auth", protected_auth_routes())
        // Admin routes
        .nest("/admin", admin_routes())
}

fn public_auth_routes() -> Router<AppState> {
    Router::new()
        .route("/register/begin", post(auth::register_begin))
        .route("/register/finish", post(auth::register_finish))
        .route("/login/begin", post(auth::login_begin))
        .route("/login/finish", post(auth::login_finish))
        .route("/recover/begin", post(auth::recover_begin))
        .route("/recover/finish", post(auth::recover_finish))

fn protected_auth_routes() -> Router<AppState> {

        .route("/logout", post(auth::logout))
        .route("/logout/all", post(auth::logout_all))
        .route("/passkeys", get(auth::list_passkeys))
        .route("/passkeys/{id}", patch(auth::rename_passkey))

        .route("/passkeys/register/finish", post(auth::add_passkey_finish))
        .route("/recovery-codes/regenerate", post(auth::regenerate_recovery_codes))
}

fn admin_routes() -> Router<AppState> {
    Router::new()
        .route("/invitations", post(auth::create_invitation))

        .route("/users", get(auth::list_users))

        .route("/api-keys", post(auth::create_api_key))
        .route("/api-keys", get(auth::list_api_keys))

}
```
