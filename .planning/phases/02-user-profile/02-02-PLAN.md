Implement `UserRepository` for `PostgresUserRepository` with all 5 methods:

- **save**: Build `users::ActiveModel` with `Set(...)` for all fields from domain `User`. Insert via `users::Entity::insert(active_model).exec_with_returning(&self.db)`. Map `DbErr` to `RepositoryError`: for unique violations, sea-orm wraps sqlx errors. Check `DbErr::Query(RuntimeErr::SqlxError(..))` or check the error string for "duplicate key" / "unique constraint" and map to `UniqueViolation("handle")`. Convert returned `Model` to domain `User`.

- **find_by_id**: `users::Entity::find_by_id(id).one(&self.db)`. Map `Option<Model>` to `Option<User>` via `From`.

- **find_by_handle**: `users::Entity::find().filter(Expr::cust("LOWER(handle) = LOWER($1)").bind(handle)).one(&self.db)`. This ensures case-insensitive matching per D-08.

- **list**: Build query with `users::Entity::find().order_by_desc(users::Column::CreatedAt).order_by_desc(users::Column::Id)`. If `!include_inactive`, add `.filter(users::Column::IsActive.eq(true))`. If cursor is `Some((cursor_time, cursor_id))`, add the composite condition: `(created_at < cursor_time) OR (created_at = cursor_time AND id < cursor_id)` using `sea_orm::Condition::any()`. Set `.limit(limit)`. Execute `.all(&self.db)`.

- **update**: Build `users::ActiveModel` from domain `User` with all fields as `Set(...)`, then call `.update(&self.db)`. Map errors same as save.
