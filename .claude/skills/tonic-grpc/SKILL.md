## Key Patterns

### Include Generated Code

```rust
pub mod my_service {
    tonic::include_proto!("my.package");
}
```

### Implement Server

```rust
use tonic::{Request, Response, Status};

pub struct MyServiceImpl { db: DatabaseConnection }

#[tonic::async_trait]
impl my_service::my_service_server::MyService for MyServiceImpl {
    async fn get_item(
        &self,
        request: Request<GetItemRequest>,
    ) -> Result<Response<GetItemResponse>, Status> {
        let req = request.into_inner();
        let item = self.db.find(req.id).await
            .map_err(|e| Status::internal(e.to_string()))?
            .ok_or_else(|| Status::not_found("item not found"))?;
        Ok(Response::new(GetItemResponse { item: Some(item) }))
    }
}
```

### Start Server

```rust
use tonic::transport::Server;

Server::builder()
    .add_service(MyServiceServer::new(service_impl))
    .serve("[::1]:50051".parse()?)
    .await?;
```

### Client Connection

```rust
let mut client = MyServiceClient::connect("http://[::1]:50051").await?;
let response = client.get_item(GetItemRequest { id: 1 }).await?;
let item = response.into_inner();
```

## Status Code Mapping

| Domain Error | tonic Status |
|-------------|--------------|
| Not found | `Status::not_found(msg)` |
| Already exists | `Status::already_exists(msg)` |
| Invalid argument | `Status::invalid_argument(msg)` |
| Permission denied | `Status::permission_denied(msg)` |
| Internal error | `Status::internal(msg)` |
| Unauthenticated | `Status::unauthenticated(msg)` |
| Unavailable | `Status::unavailable(msg)` |

## When Writing Code

1. Always use `request.into_inner()` to extract the protobuf message
2. Map domain errors to appropriate `Status` codes
3. Return `Response::new(message)` for success
4. Use `#[tonic::async_trait]` on service implementations
5. Server takes ownership of the service impl via `MyServiceServer::new()`

## When Answering Questions

1. `tonic::include_proto!` includes code generated by `tonic-build` in `build.rs`
2. `Request<T>` wraps the protobuf message with metadata (headers)
3. `Response<T>` wraps the response message with metadata
4. `Status` is tonic's error type — maps to gRPC status codes
5. Client methods return `Result<Response<T>, Status>`
